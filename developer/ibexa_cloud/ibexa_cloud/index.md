# Ibexa Cloud

Host your Ibexa projects on the cloud.

Ibexa Cloud is a cloud hosting platform that enables you to host your application in the cloud by using the Upsun service.

- [Ibexa Cloud product guide](../ibexa_cloud_guide/index.md): Learn how to host your application and improve your business processes by using Ibexa Cloud hosting platform.
- [Install on Ibexa Cloud](../install_on_ibexa_cloud/index.md): Install and configure Ibexa DXP to run in cloud using Ibexa Cloud.
- [Ibexa Cloud CLI](../ibexa_cloud_cli/index.md): Use the Ibexa Cloud CLI to manage your IIbexa Cloud projects from the command line.
- [Environment variables on Ibexa Cloud](../environment_variables/index.md): Automatically generated environment variables based on Ibexa Cloud relationships and routes.
- [DDEV and Ibexa Cloud](../ddev_and_ibexa_cloud/index.md): Use DDEV to run an Ibexa Cloud project locally.
