# Tutorials

Get started with tutorials to learn how to create a site with Ibexa DXP

Get started with tutorials to learn how to create a site with Ibexa DXP.

> **Note: Note**
>
> Remember that each tutorial should be performed on a clean project to avoid conflicts with added or modified files.

- [Beginner tutorial](../beginner_tutorial/beginner_tutorial/index.md): Go through a beginner tutorial which presents the Ibexa DXP content model and show how to configure and use templates to create a basic site.
- [Page and Form tutorial](../page_and_form_tutorial/page_and_form_tutorial/index.md): Go through a Page and Form tutorial to learn how to create modular Sites and how to manage forms and their submissions.
- [Creating a Point 2D field type](../generic_field_type/creating_a_point2d_field_type/index.md): Go through a field type tutorial to learn how to create a custom field type based on the built-in Generic field type.
