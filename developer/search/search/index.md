# Search

Ibexa DXP search functionalities allow working with three search engines and using search API to run complex and precise queries about content and products.

Ibexa DXP exposes a very powerful [Search API](../search_api/index.md), allowing both full-text search and querying the content repository by using several built-in Search Criteria and Sort Clauses. These are supported across different search engines, allowing you to plug in another search engine without changing your code.

- [Search engines](../search_engines/search_engines/index.md): Learn about different search engines that are supported by Ibexa DXP.
- [Elasticsearch search engine](../search_engines/elasticsearch/elasticsearch_overview/index.md): Elasticsearch search engine overview.
- [Solr search engine](../search_engines/solr_search_engine/solr_overview/index.md): Solr search engine overview.
- [Search API](../search_api/index.md): You can search for content, locations and products by using the PHP API. Fine-tune the search with Search Criteria, Sort Clauses and Aggregations.
- [Search Criteria and Sort Clauses](../search_criteria_and_sort_clauses/index.md): Search Criteria and Sort Clauses help you fine-tune searches done by using the Search API.
- [Create custom Search Criterion](../extensibility/create_custom_search_criterion/index.md): Create custom Search Criterion to use with Solr and Elasticsearch search engines.
- [Create custom Sort Clause](../extensibility/create_custom_sort_clause/index.md): Create custom Sort Clause to use with Solr and Elasticsearch search engines.
- [Create custom Aggregation](../extensibility/create_custom_aggregation/index.md): Create custom Aggregation to use with Solr and Elasticsearch search engines.
