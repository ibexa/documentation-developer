# MatchAll Criterion

MatchAll Search Criterion

The [`MatchAll` content](../../../../../../ibexa/core/src/contracts/Repository/Values/Content/Query/Criterion/MatchAll.php) and [`MatchAll` product](../../../../../../ibexa/product-catalog/src/contracts/Values/Product/Query/Criterion/MatchAll.php) search criteria are auxiliary criteria that returns all search results. They're used internally when no filter or query is provided on a Query object.

The criteria take no arguments.
