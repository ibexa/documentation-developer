# Payment Sort Clauses

Payment Sort Clauses

Editions: Commerce

Payment Sort Clauses are only supported by [Payment Search (`PaymentServiceInterface::findPayments`)](../../../commerce/payment/payment_api/index.md#get-multiple-payments).

By using Sort Clauses you can sort payments by specific attributes, for example: creation date, status, and more.

| Sort Clause                                                                                                    | Sorting based on                              |
| -------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| [Id](../payment_id_sort_clause/index.md)                 | Payment ID                                    |
| [Identifier](../payment_identifier_sort_clause/index.md) | Payment identifier                            |
| [CreatedAt](../payment_createdat_sort_clause/index.md)   | Date and time when payment was created        |
| [UpdatedAt](../payment_updatedat_sort_clause/index.md)   | Date and time when payment status was updated |
| [Status](../payment_status_sort_clause/index.md)         | Payment status                                |
