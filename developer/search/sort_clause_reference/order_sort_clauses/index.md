# Order Sort Clauses

Order Sort Clauses

Editions: Commerce

Order Sort Clauses are only supported by [Order Search (`OrderService::findOrders`)](../../../commerce/order_management/order_management_api/index.md#get-multiple-orders).

By using Sort Clauses you can sort orders by specific attributes, for example: creation date, status, and more.

| Sort Clause                                                                                            | Sorting based on                            |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| [Id](../order_id_sort_clause/index.md)           | Order ID                                    |
| [Created](../order_created_sort_clause/index.md) | Date and time when order was created        |
| [Updated](../order_updated_sort_clause/index.md) | Date and time when order status was updated |
| [Status](../order_status_sort_clause/index.md)   | Order status                                |
