# Users

You can access all users and user groups in the Users tab.

[Users](../../../users/users/index.md) in Ibexa DXP are treated the same way as content items. They're organized in groups such as *Guests*, *Editors*, *Anonymous*, which makes it easier to manage them and their permissions. You can access all users and user groups in the **Admin** panel by selecting **Users**.

![Users and user groups](https://doc.ibexa.co/en/5.0/administration/img/admin_panel_users.png "Users and user groups")

> **Caution: Caution**
>
> Be careful not to delete an existing user account. If you do this, content created by this user can be broken and the application can face malfunction.
