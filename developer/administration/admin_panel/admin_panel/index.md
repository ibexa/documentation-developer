# Admin panel

Ibexa DXP back office contains managements options for permissions, users, languages, content types, and system information.

Once you set up your environment you can start your work as an administrator. You can find key tools in **Admin** panel.

To access **Admin** panel, click the icon: ![Admin panel Icon](https://doc.ibexa.co/en/5.0/administration/img/admin_panel_icon.png).

- [Users](../users_admin_panel/index.md): You can access all users and user groups in the Users tab.
- [Roles](../roles_admin_panel/index.md): To give users an access to your website you need to assign them roles in the Admin Panel.
- [URL Management](../url_management_admin_panel/index.md): URL Management lets you manage external URL addresses and URL wildcards.
- [Languages](../languages_admin_panel/index.md): Ibexa DXP offers the ability to create multiple translations of your website.
- [Segments](../segments_admin_panel/index.md): You can use segments to display specific content to specific users.
- [Corporate](../corporate_admin_panel/index.md): You can manage companies profiles in the Admin Panel.
- [Workflow](../workflow_admin_panel/index.md): The workflow functionality passes a content item version through a series of stages.
- [System Information](../system_information_admin_panel/index.md): System information provides basic system information such as versions of all installed packages.
