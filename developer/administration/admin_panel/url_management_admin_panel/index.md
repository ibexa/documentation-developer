# URL Management

URL Management lets you manage external URL addresses and URL wildcards.

You can manage external URL addresses and URL wildcards in the **Admin** panel. Configure URL aliases to have human-readable URL addresses throughout your system.

For more information, see [URL management](../../../content_management/url_management/url_management/index.md).
