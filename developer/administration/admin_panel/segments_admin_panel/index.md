# Segments

You can use segments to display specific content to specific users.

Editions: Experience

You can use segments to display specific content to specific [users](../../../users/users/index.md). They're used out of the box in the Targeting block in the page.

You can collect segments in segment groups:

![Segment groups](https://doc.ibexa.co/en/5.0/administration/img/admin_panel_segment_groups.png)

Each segment group can contain segments that you can target content for.

![Segment](https://doc.ibexa.co/en/5.0/administration/img/admin_panel_segment.png)

You can assign users to segments [through the API](../../../users/segment_api/index.md#assigning-users).
