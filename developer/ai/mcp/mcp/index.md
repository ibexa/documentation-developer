# MCP Servers

Overview of MCP resources in Ibexa DXP

Editions: LTS Update

The Model Context Protocol (MCP) and MCP Servers allow AI agents to interact with the system in a structured way. The feature is available as an [LTS Update](../../../ibexa_products/editions/index.md#lts-updates) since v5.0.8.

- [MCP Servers product guide](../mcp_guide/index.md): MCP servers expose tools, specialized prompts, and resources to AI agents.
- [Install and configure MCP Servers](../mcp_config/index.md): Configure an MCP server that exposes built-in and custom tools, prompts, and resources.
- [Work with MCP servers](../mcp_usage/index.md): Create custom capabilities for your MCP servers and test them.
