# Artificial Intelligence

AI interactions with Ibexa DXP

Ibexa DXP includes built-in AI capabilities. For example, it can provide recommendations to product customers and content readers with the [Raptor connector](../../recommendations/raptor_integration/raptor_connector_guide/index.md), and assist editors in the back office with [AI Actions](../ai_actions/ai_actions_guide/index.md). The platform is also open to external AI integrations through [MCP (Model Context Protocol) servers](../mcp/mcp_guide/index.md), which allow AI agents to interact with the system in a standardized way. AI solutions are extensible. You can create [custom AI actions](../ai_actions/extend_ai_actions/index.md) or expose [new MCP server capabilities](../mcp/mcp_usage/index.md).

AI integration goes even further:

- Some AI agents can learn how to use the [REST](../../api/rest_api/rest_api_usage/rest_api_usage/index.md) or [GraphQL](../../api/graphql/graphql/index.md) APIs.

- Other, like those integrated into IDEs, can learn how to use the [PHP API](../../api/php_api/php_api/index.md) and assist you in code development.

- [AI Actions](../ai_actions/ai_actions/index.md): AI Actions help editors by automating repetitive tasks.

- [MCP Servers](../mcp/mcp/index.md): Overview of MCP resources in Ibexa DXP
