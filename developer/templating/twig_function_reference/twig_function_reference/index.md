# Twig function reference

Built-in Twig functions speed up rendering content in Twig templates.

In addition to the [native functions provided by Twig](https://twig.symfony.com/doc/3.x/functions/index.html), and [Twig extensions provided by Symfony](https://symfony.com/doc/7.4/reference/twig_reference.html), Ibexa DXP offers the following custom Twig functions and filters:

- [Cart Twig functions](../cart_twig_functions/index.md): Cart Twig functions enable checking whether product can be added to cart and formatting the price.
- [Catalog Twig functions](../catalog_twig_functions/index.md): Catalog Twig functions enable getting and rendering certain catalog information.
- [Checkout Twig functions](../checkout_twig_functions/index.md): Checkout Twig functions return information about the checkout process, and total values related to cart and cart items.
- [Content Twig functions](../content_twig_functions/index.md): Content Twig function enable rendering whole content items and their information.
- [Twig Component functions](../component_twig_functions/index.md): Twig Components allow you to inject custom widgets into selected templates
- [Field Twig functions](../field_twig_functions/index.md): Field Twig function enable rendering content fields, their values and their information.
- [Page Twig functions](../page_twig_functions/index.md): Page field and page block Twig functions provide access to configuration.
- [Product Twig functions](../product_twig_functions/index.md): Product Twig functions enable getting products and their attributes in templates.
- [Recommendations Twig functions](../recommendations_twig_functions/index.md): Recommendations Twig Functions
- [Site context Twig functions](../site_context_twig_functions/index.md): Site context Twig function determines if given location is site context-aware.
- [Storefront Twig functions](../storefront_twig_functions/index.md): Storefront Twig function enable controlling the rendering of storefront elements.
- [Icon Twig functions](../icon_twig_functions/index.md): Icon Twig functions enable referencing SVG icons in templates.
- [Image Twig functions](../image_twig_functions/index.md): Image Twig functions enable rendering images in a specific variation.
- [URL Twig functions](../url_twig_functions/index.md): URL Twig functions enable rendering URLs and routes.
- [Date Twig filters](../date_twig_filters/index.md): Use date Twig filters to select the date and time format used in templates.
- [AI Actions Twig functions](../ai_actions_twig_functions/index.md): AI Actions functions allows you to embed AI Actions in your templates
- [Discounts Twig functions](../discounts_twig_functions/index.md): Discounts Twig Functions allow you to operate on discounts in your templates.
- [Quable Twig functions](../quable_twig_functions/index.md): Twig functions exposed by the Quable connector.
