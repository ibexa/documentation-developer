# Infrastructure and maintenance

Learn how to handle cache, use a clustering setup, configure databases and ensure your installation is performing well.

- [Cache](../cache/cache/index.md): For caching, Ibexa DXP offers both HTTP cache for content views, and persistence cache.
- [Clustering](../clustering/clustering/index.md): Clustering enables you to host one installation of Ibexa DXP on multiple servers.
- [Performance](../performance/index.md): Ensure that your Ibexa DXP installation performs well by following our set of recommendations.
- [Background tasks](../background_tasks/index.md): Use Ibexa Messenger to run processes in the background and conserve system resources.
- [Databases](../databases/index.md): Ibexa DXP can use MySQL, PostgreSQL or MariaDB as its database.
- [Environments](../environments/index.md): In Ibexa DXP you can use environment provided by Symfony in virtual host configuration, and to create custom environments.
- [Support and maintenance FAQ](../support_and_maintenance_faq/index.md): See how you can resolve common issues and report a Customer Support ticket.
