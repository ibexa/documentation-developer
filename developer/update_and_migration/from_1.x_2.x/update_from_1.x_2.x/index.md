# From 1.13 and 2.x

Update your installation to the latest v2.5 version from v1.13 or earlier v2 version.

This update procedure applies if you're using:

- v1.13
- v2.x
- v2.5 lower than the latest v2.5.x

Go through the following steps to update to the latest v2.5 LTS (v2.5.30).

1. [Check out a version](../update_app_to_2.5/index.md#1-check-out-a-version)
2. [Resolve conflicts](../update_app_to_2.5/index.md#2-resolve-conflicts)
3. [Update the app](../update_app_to_2.5/index.md#3-update-the-app)
4. [Update the database](../update_db_to_2.5/index.md#4-update-the-database)
5. [Finish the update](../update_db_to_2.5/index.md#5-finish-the-update)
