# Update from v4.3.x to v4.4

Update your installation to the latest v4.4 version from v4.3.x.

This update procedure applies if you're using the newest v4.3 installation.

This release deprecates all Commerce packages inIbexa DXP. They will be removed in v5. Until that time, they will be maintained by Ibexa with fixes, including security fixes, but they won't be further developed. Old packages are replaced by [the all-new Ibexa Commerce packages](../../../release_notes/ibexa_dxp_v4.4/index.md#all-new-ibexa-commerce-packages).

For that reason, there are two update routes you can take.

A. If you don't use Commerce functionalities, you can proceed with removing them.

B. If you use Commerce functionalities based on the deprecated packages, you can continue to use them for the time being.

- [Update with new Commerce packages](../update_from_4.3_new_commerce/index.md): Update procedure to v4.4 for people who don't use Commerce packages and can remove them.
- [Update with old Commerce packages](../update_from_4.3_old_commerce/index.md): Update procedure to v4.4 for people who use deprecated Commerce packages and want to keep them.
