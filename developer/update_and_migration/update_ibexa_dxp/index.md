# Updating Ibexa DXP

Update your installation to the latest supported version.

To update Ibexa DXP to a newer version, select the version you're currently using:

**I am using v1.13 or v2.x**

If you have a v1.13 installation, or a v2.x installation lower than the latest v2.5, [update to the v2.5 LTS](../from_1.x_2.x/update_from_1.x_2.x/index.md).

Afterwards, it's strongly recommended to [update to the v3.3 LTS](../from_2.5/update_from_2.5/index.md), then [update to v4.6 LTS](../from_4.5/update_from_4.5/index.md) (through [v4.0](../from_3.3/to_4.0/index.md) up to v4.6), and finally [to the lastest v5.0 LTS](../from_4.6/update_to_5.0/index.md).

**I am using v2.5**

If you have a v2.5 installation, [update to the v3.3 LTS](../from_2.5/update_from_2.5/index.md).

Afterwards, it's strongly recommended to also [update to v4.6 LTS](../from_4.5/update_from_4.5/index.md) (through [v4.0](../from_3.3/to_4.0/index.md) up to v4.6), and finally [to the lastest v5.0 LTS](../from_4.6/update_to_5.0/index.md).

**I am using v3.3**

If you already have a v3.3 installation, [update to the latest v3.3 version](../from_3.3/update_from_3.3/index.md).

Afterwards, it's strongly recommended to also [update to v4.6 LTS](../from_4.5/update_from_4.5/index.md) (through [v4.0](../from_3.3/to_4.0/index.md) up to v4.6), and finally [to the lastest v5.0 LTS](../from_4.6/update_to_5.0/index.md).

**I am using v4.x**

- If you have a v4.x installation prior to v4.6, [update to the v4.6 LTS](../from_4.5/update_from_4.5/index.md).
- If you have a v4.6 installation, [update to the latest patch v4.6.32](../from_4.6/update_from_4.6/index.md).

Afterwards, it's strongly recommended to also [update to the lastest v5.0 LTS](../from_4.6/update_to_5.0/index.md).

**I am using v5.0**

Refer to the [v5.0 update page](../from_5.0/update_from_5.0/index.md) to make sure you're staying up to date.
