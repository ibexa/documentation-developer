# Users

Users in Ibexa DXP refer to all kinds of user accounts, such as administrators, editors, managers or shop customers.

Users in Ibexa DXP refer to all kinds of user accounts: administrators, editors, managers, or shop customers. All such user accounts have the same underlying mechanism and enable you to control access to the application, both the back office and the website front, by using the [permission system](../../permissions/permissions/index.md).
