# Multisite

Multisite enables hosting multiple websites with different content, templates and configuration by using one repository.

A multisite setup enables you to create more than one site in one installation of Ibexa DXP.

Multisite configuration is done using [SiteAccesses](../siteaccess/siteaccess/index.md).

To quickly set up new sites with predefined site templates, use [Site Factory](../site_factory/site_factory/index.md).

- [SiteAccess](../siteaccess/siteaccess/index.md): SiteAccesses enable you to provide separate configuration for each site in a multisite setup.
- [Set up campaign SiteAccess](../set_up_campaign_siteaccess/index.md): Create a special SiteAccess to host a campaign site with different content subtree.
- [Set up translation SiteAccess](../set_up_translation_siteaccess/index.md): Set up SiteAccesses to hold different language versions of a site.
- [Multisite configuration](../multisite_configuration/index.md): Configure SiteAccesses to serve different content in different layouts.
- [Site Factory](../site_factory/site_factory/index.md): Site Factory allows creating multiple sites (SiteAccesses) from the back office.
- [Site Factory configuration](../site_factory/site_factory_configuration/index.md): Configure Site Factory, including site skeletons.
