# Dashboard

Get to know about dashboard.

Dashboard is the first screen that you see after you log into Ibexa DXP. It provides users a quick overview about specific content to make better business decisions based on data and work more efficiently with a clear and effortless access to important information.

Default dashboard in Ibexa Headless contains the following blocks:

- [Review queue](../dashboard_block_reference/index.md#review-queue-block)
- [My content](../dashboard_block_reference/index.md#my-content-block)
- [Common content](../dashboard_block_reference/index.md#common-content-block)

![Dashboard - Headless edition](https://doc.ibexa.co/projects/userguide/en/5.0/getting_started/img/dashboard_headless.png "Default dashboard in Headless edition")

You can return to the **Dashboard** screen from any other page by clicking the Ibexa logo on the left of the top bar, or the home icon in the main menu.

![Dashboard icon](https://doc.ibexa.co/projects/userguide/en/5.0/getting_started/img/dashboard_icon.png)

## Customizable dashboard (Experience, Commerce)

You can customize the dashboard depending on your needs. A customized dashboard contains a set of widgets selected by the user.

Customization allows you to quickly visit the areas that are used more often and exclude those less important:

- Selected widgets boost productivity by highlighting vital data and helping in decision making
- Predefined and custom layouts improve visibility for efficient task and deadline management

By default, dashboard in Ibexa Experience and Ibexa Commerce contains the following blocks:

- [Quick actions](../dashboard_block_reference/index.md#quick-actions-block)
- [Recent activity](../dashboard_block_reference/index.md#recent-activity-block)
- [Ibexa News](../dashboard_block_reference/index.md#ibexa-news-block)
- [Review queue](../dashboard_block_reference/index.md#review-queue-block)
- [My content](../dashboard_block_reference/index.md#my-content-block)
- [Common content](../dashboard_block_reference/index.md#common-content-block)

![Dashboard - Experience and Commerce edition](https://doc.ibexa.co/projects/userguide/en/5.0/getting_started/img/dashboard.png "Default dashboard in Experience and Commerce edition")

For more information, see [Work with dashboard](../work_with_dashboard/index.md).
