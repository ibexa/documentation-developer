# MatchAll Criterion

The [`MatchAll` content search criterion](/api/php_api/php_api_reference/classes/Ibexa-Contracts-Core-Repository-Values-Content-Query-Criterion-MatchAll.html) and [`MatchAll`](/api/php_api/php_api_reference/classes/Ibexa-Contracts-ProductCatalog-Values-Product-Query-Criterion-MatchAll.html) are auxiliary criteria that returns all search results.
It's used internally when no filter or query is provided on a Query object.

The Criteria take no arguments.
