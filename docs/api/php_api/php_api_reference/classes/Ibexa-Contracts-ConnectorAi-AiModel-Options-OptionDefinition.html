OptionDefinition

OptionDefinition.php : 19
Read-only
Final

The {@see self::with*()} methods return a new instance validated as a whole, against the current default: to narrow the range or choices so that they exclude the default, clear it first, e.g. `$definition->withDefault(null)->withChoices(['low', 'high'])->withDefault('low')`.
