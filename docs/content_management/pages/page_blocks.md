# Page blocks

[[= product_name =]] ships with a number of page blocks.
For a list of all page blocks that are available out-of-the-box, see [Page block reference]([[= user_doc =]]/content_management/block_reference/) in the user documentation.

## Block overrides

You can change the name, category, icon, or availability of a block type.

1. In the left panel, go to **Administration** -> **SiteAccess Configuration**.
1. Choose the SiteAccess that you want to override the block type for. Choosing none or admin has no effect.
1. In **Available configurations** list, click  **Page Builder Overrides**.
1. In **Edit configuration** section, under **Block overrides**, click **Add** to add a block type override.
1. Expand the **Block identifier** drop-down list and select a block that you want to override.
1. Define the override details and click **Save** to apply your changes.

- To add more overrides, click **Add** again.
- To remove an existing override, repeat the steps to display a list of defined overrides and click the trash icon at the end of a row.
