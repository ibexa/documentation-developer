# Keywords field type

This field type stores one or several keywords.

| Name     | Field type identifier |
|----------|-----------------------|
| Keywords | `ibexa_keyword`       |

## Field value

The field value is an array of keywords, each one a string.

``` json
{
    "fieldDefinitionIdentifier": "tags",
    "languageCode": "eng-GB",
    "fieldValue": ["Ibexa", "Enterprise", "User Experience Management"]
}
```
